What this is. Every clip is rendered directly from the game's own opcode data (engine/audio/audio_engine.fab's sfx_* arrays) through an NES 2A03 APU pulse/noise-channel simulator — same duty cycle, same period tables, same DAC curve the real hardware uses. What you hear here is what plays in-game.

Events lists every place in the game that currently plays (or could plausibly play) a sound, grouped by category. Rows outlined in amber have no sound bound at all. Click a row's dropdown to try a different clip against that event — the change is tracked but nothing is written back to the game yet.

SFX Library is every clip on its own, independent of any event, so you can audition the full set before deciding.

Saving. Once you're happy, use Export at the bottom to download (or copy) a JSON file of your choices. Hand that back and the actual code changes get made from it — this page never touches the game itself.
