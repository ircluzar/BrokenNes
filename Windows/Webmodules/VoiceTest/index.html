ℹ️ About

This page allows you to test the speak.js TTS library with various configuration parameters.

  • Speed: Controls how fast the speech is (words per minute)
  • Pitch: Controls the pitch/tone of the voice
  • Volume: Controls the amplitude (loudness) of the voice
  • Variant: Different voice characteristics (robotic, whisper, etc.)
  • Voice: Language and accent selection
