------------------------------------------------------------------------------
  BrokenNes                                                      Deck Builder
------------------------------------------------------------------------------

  BrokenNes: a DIY NES emulator hardware playground,
  and glitch-friendly experiment box built around swappable cores,
  runtime tools, and don't worry too much if it's a bit rough on the edges

  Starting the program:
  Simply double-click on START.bat to start BrokenNes.

  If that does not work for some reason, you may navigate
  in the BrokenNes folder and open BrokenNes.Windows.exe instead.

------------------------------------------------------------------------------
  WHAT IT DOES
------------------------------------------------------------------------------

  * Loads and runs NES ROMs
  * Lets you switch CPU / PPU / APU cores at runtime
  * Includes save support, recent ROM history, and reset / reload flow
  * Includes a variety of real-time corruption tools and novel stuff
  * Shares emulator logic with the broader BrokenNes codebase

------------------------------------------------------------------------------
  CURRENT FLAVOR
------------------------------------------------------------------------------

  * Kinda broken by design, ngl
  * Some features are polished, some experimental, some gloriously odd
  * Timing quirks and rough edges may appear depending on game and core choice
  * If it looks slightly haunted, that is within spec

------------------------------------------------------------------------------
  SKIPPING THE DECK BUILDER GAME
------------------------------------------------------------------------------

  If you do not want to play the Deck Builder game and just want to mess 
  around with the emulator and all the various cores and tools, go to Options 
  and click on Unlock Everything to completely unlock all of BrokenNes.

------------------------------------------------------------------------------
  KEYBOARD DEFAULTS
------------------------------------------------------------------------------

  D-Pad     : Arrow Keys
  A Button  : X
  B Button  : Z
  Start     : S
  Select    : A
  Pause     : Space
  Load ROM  : Ctrl+O
  Reset ROM : Ctrl+R

------------------------------------------------------------------------------
  NOTES
------------------------------------------------------------------------------

  * Save Data is kept at
      %APPDATA%\BrokenNes\

  * Core menus are populated dynamically from the emulator implementation

------------------------------------------------------------------------------
  EXPECTATIONS
------------------------------------------------------------------------------

  Bring a ROM, try different cores, poke at the edges, and see what holds.
  BrokenNes is as much about running games as it is about exploring how the
  machine behaves when you swap parts, stress timing, and lean into the weird.
