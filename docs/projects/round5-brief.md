## The user's batch, in their words (summarised)

1. **D-pad protection.** Pressing opposite directions at once is impossible on real d-pads, so protection against it is default behaviour, enabled by default, and can be disabled in the input controls.
2. **No more "Bogue".** The VST is just **BrokenNes2**; the label in the software must not say Bogue.
3. **Corruption integration in the VST.** One of the main goals of the BrokenNes VST is to take corrupted instruments from corruptions and make music with them. Farm corruptions in BrokenNes until there are good corrupted instruments, save them in a **stockpile**; in the VST open the stockpile, select the corruption, start it, then perform **Instrument Runaway** to take over the corrupted instruments (from the SPC700 on the SNES, a priority because that chip works very well with corruptions; later the Sega and 8-bit consoles). Whatever is corrupted must also persist through a saved FL project (another agent is making the VST save the whole game state in the project).
4. **BrokenNes Nano.** A spin-off like BrokenNes Lite, web based, focused on one thing: BrokenNes as a **NES synth embedded in a web page** (a page that needs bleeps and bloops embeds a minimised version of the BrokenNes VST).
5. **BrokenDev.** A new module, for developers only, that turns our homebrew tooling into a devkit environment inside BrokenNes. The VST would make the music for the games. The long-term path: compose a song in FL Studio, have the plugin turn it into a ROM, preview it in the emulator to check it replays correctly, export a file, import it into a game during development. Import the three projects from `P:\BrokenDev`: **SMB1 Topaz** (knowledge only, see below), **VRUN_Nes_Dev** (VRUN NES demake, plus Nested VRUN, the mapper 30 variant used for the SNES), **SuperVRUN_dev** (the current SNES project). Build these versions and prove they all work on BrokenNes: SMB1 (NES, and a Nested version for the SNES); VRUN NES demake (NES; SNES through Nested; the SNES variant enhanced for the SNES); SuperVRUN.
