## What changed in the prompt and playbook
1. Menu presses: 5 frames, after the menu has been up ~10 frames (was: 1-frame taps).
2. "Never plan more than one step ahead while enemies are on screen" (the blind script killed Mario).
3. open_rom failure is a give-up rule with grade Nothing; the misleading "CPU core did not apply" text is explained.
4. `checkFindings` counts are not a grading signal.
5. SMB and MM2 watch addresses marked verified.

## Cost seen
~12 tool calls per game to reach gameplay and look around (4 screenshots); a real T2 with play_step should need 60-120 calls per game.
