# Sega game rosters (20 + 20 + 20)

The climb lists for the three Sega tracks, easiest first, picked from the user's library (`X:\EMULATION\Sega Master System`, `Sega Game Gear`, `Sega Genesis`; 342, 665 and 948
files). File names only: ROMs are never committed. The live status of each game is on the Sega Core Lab dashboard; this page is the durable list behind it. Master System files
are `.7z` archives (the library keeps one game per archive). `(Europe)` titles are PAL, which the region-aware timing certifies headless.

The ladder is hardware demand, not fame: plain pictures first, then scrolling and sprite limits, then line-interrupt and raster effects, then battery saves and large or unusual
mappers, with one hard final game per console.
